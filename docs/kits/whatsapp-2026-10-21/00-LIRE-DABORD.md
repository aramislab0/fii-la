# Fii La — Kit complet de création et de passation

Édition du 21/10/2026, Africa/Dakar. Auteur de compilation : CHATGPT/Codex, VP produit. Modèle exact non exposé.

## VISION / ÉTAT ACTUEL / PROCHAINE ACTION UNIQUE

**VISION :** messages WhatsApp Fii La premium, humains et immédiatement compréhensibles ; une seule action, photographies pertinentes, mouvement discret et continuité avec le parcours ouvert.

**ÉTAT ACTUEL :** direction visuelle, direction photographique et image signature retenues dans la conversation. Ce kit contient les maquettes, les sources photographiques illustratives, les essais MP4 et tous les mandats préparés. Il ne constitue pas une intégration, une vidéo aux gestes réellement animés, une acceptation Meta ou une recette sur téléphone.

**PROCHAINE ACTION UNIQUE :** Claude lit le mandat consolidé, réconcilie avec son dépôt courant, puis finalise le pilote « Indiquer mon entrée » avec la nouvelle image signature et la version animée à valider.

## Contenu

- `assets/photos/` : 3 images sources sans texte ni interface, dont `signature.png`, image retenue.
- `assets/animations/` : 3 essais MP4 de 5 secondes. Mouvement de cadrage/lumière uniquement ; personnages fixes.
- `assets/brand/` : logo source Fii La issu du dépôt.
- `assets/fonts/` : Montserrat 600/700, WOFF2 source et licence OFL.
- `docs/screenshots/whatsapp-v1/` : 7 maquettes de messages (deux versions Ambassadeur et cinq autres usages).
- `docs/screenshots/whatsapp-v2/` : 3 maquettes du gabarit photographique. **Leurs anciennes illustrations sont historiques ; utiliser désormais les sources dédiées d'assets/photos/.**
- `docs/design/whatsapp/` : catalogue de 6 messages, règles visuelles, passation et manifeste d'origine.
- `docs/historique/` : mandat source Agents/Ambassadeurs et notice de l'essai motion. Lire leur en-tête et les statuts actuels avant usage.
- `scripts/render_motion.py` : source modifiable pour reconstruire les essais de caméra.
- `MANIFEST.json` et `VERIFICATION-DU-PAQUET.json` : inventaire, empreintes et contrôles locaux.

## Autorité et limites

Les décisions directes du fondateur consignées dans ce kit priment sur les anciennes préférences créatives de ce kit. Le dépôt réel courant fait foi pour l'état technique ; le relire avant écriture. Les fichiers de travail historiques ne doivent pas être interprétés comme une nouvelle livraison.

L'écriture GitHub par la connexion du VP a été refusée avec 403 lors de la préparation de WHATSAPP-001. Aucune nouvelle tentative n'est revendiquée pour cette compilation. L'import du kit reste à faire par une connexion autorisée. Le problème d'accès a été reporté par le fondateur ; ce kit n'essaie pas de le contourner.

Le mandat Agents/Ambassadeurs a, lui, été observé enregistré par Claude, avec inventaire terminé et suite en cours, sur l'état `83614d7296fc4a4262489e3d084fea60837e1ac0` lu dans la session. Cette observation n'est pas une vérification de son état après ce commit.

Les scènes sont générées et illustratives. Elles ne prouvent ni une vraie adresse, ni un vrai client, ni une équipe réelle. Aucun secret ou identifiant de gestion n'est inclus. Les messages montrent des données fictives ; les anciennes maquettes ne donnent aucun droit d'envoi réel.
